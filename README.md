# Income Differentiation
This project talks about the social cause of income differentiation across many areas. 

**Live site:** https://jason-jc-lee.github.io/IncomeDifferentiation/

## About
Income differentiation is an issue that has been around for a while; it's everywhere and is something that people have simply learned to live with despite its wrongs. This site provides general information on what this topic is about and spareads awareness. 

## Pages
- `index.html`: Main/Home page, shows an overview about the income differentiation, provides links, and its current impacts on the world.
- `page1.html`: The objective.
- `page2.html`: Additional information about income differentiation.

## Built With

- Daily greeting based on the current day of the week
